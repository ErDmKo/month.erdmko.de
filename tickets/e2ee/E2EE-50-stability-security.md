# E2EE-50 Stability & Security

## Depends on
- `E2EE-30`, `E2EE-40`

## Goal
Финальная верификация: утечки, регресс-тесты, документация, деплой.

## Scope

### Аудит утечек (главный acceptance всего эпика)
- Скрипт/команда проверки живой БД после деплоя:
  `strings db.sqlite | grep -i <слово из отправленных сообщений>` → 0 совпадений
- То же для файлов вложений на диске
- Grep по кодовой базе: body/файлы не логируются (`ws-logger` в
  `assets/js/utils/ws-logger.ts` — убедиться, что не пишет plaintext в
  консоль в проде; в dev-режиме допустимо)
- Server error paths не включают содержимое body в тексты ошибок

### Регресс и стабильность
- Полный прогон: `bazel test //...`, `./tests/e2e/run.sh`
- Лимиты хранения: шифротекст раздувает строки (~+30 байт) — проверить, что
  автоочистка старых сообщений работает и при BLOB
- Reconnect WebSocket с повторным вводом фразы — история расшифровывается
- Смешанная история: сообщения до миграции отсутствуют (миграция чистит),
  убедиться что пустая история рендерится без ошибок

### Документация
- `contracts/chat/CHAT_CONTRACT.md`: финальный формат body-конверта,
  KDF-параметры, модель доверия
- README.md проекта: секция «Шифрование» — что защищено / что нет:
  - ✅ база украдена → переписка не читается
  - ✅ сервер не может читать сообщения
  - ⚠️ компрометация фразы = чтение истории (нет forward secrecy)
  - ⚠️ фразу передавать только вне чата; сверка не предусмотрена (нет
    safety number) — MITM при подмене фразы невозможен технически, но
    слабая фраза подбирается офлайн при известном slug → требование длины
  - 📌 апгрейд-путь: MLS (openmls), если понадобится per-user модель
- Домашняя страница `/chat/general`: предупреждение о вводе фразы комнаты

### Деплой
- Обычный пайплайн: `npm run build && npm run save` + ansible push
- После деплоя: healthz, живой чат-смоук скриптом
  `/tmp/opencode/ws-client.mts <room> <nick>` (join + message через
  сгенерированный энкодер)

## Tests
- Все тесты репо зелёные
- Утечек нет (критерии выше)
- Нагрузочный смоук: 50 сообщений подряд, ни одного разрыва WS
  (лимит `WS_FRAME_MAX_BYTES` учтён: конверт ≤1024 байт << лимита)

## Acceptance
- Эпик закрыт: «украли базу — переписку прочитать нельзя» подтверждено
  практической проверкой, а не только тестами
