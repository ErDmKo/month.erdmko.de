Key Features

  • Instant URL Rooms: Every URL path under /chat/{room} is an independent room you can bookmark or share.
  • WebRTC Voice Calls: One-click Opus voice chat right in your browser backed by a Rust & GStreamer media pipeline.
  • File Attachments: Stream binary file attachments with real-time chunk upload and download progress over Protobuf WebSockets.
  • Web3 & Wallet Support: Sign in with an Ethereum wallet (EIP-4361 SIWE) to claim your persistent nickname across rooms.

Frequently Asked Questions

How do I invite people to a room?

Pick any room slug (for example /chat/my-team) and share the URL. Anyone with the link can join the text and voice channel immediately.

Are private room URLs indexed by search engines?

Only curated public rooms listed on this page are indexed by search engines. Custom room URLs include a noindex directive so ad-hoc room names stay out of search results while still showing rich link previews in messengers.
